Analysis data check

This page connects in STEP_ANALYSIS mode and receives gait analysis data through the gotGait() callback function. Additionally, quaternion data is received through the gotQuat() callback function. Please refer to the source code for more details. Follow the steps below to verify functionality.

  1. Press the connect button to connect to ORPHE CORE. Once connected successfully, the Quaternion data will be displayed.
  2. Wear the ORPHE CORE on your foot and start walking. As you begin walking, values will appear in the gotGait() table.
  3. Press the resetAnalysisLogs() button to reset the gait analysis data. Walk a little and confirm that the value of steps changes to 1.
  4. Press the stopNotify() button to stop notifications for gait analysis data. The values in the gotGait() table will not update even if you walk.
  5. Press the startNotify() button to resume notifications for gait analysis data. As you walk, the values in the gotGait() table will update.
