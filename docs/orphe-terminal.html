Developer Tool

ORPHE TERMINAL

ORPHE TERMINAL is a browser-based developer tool for checking ORPHE CORE connection, Device Information, Date Time, and raw streaming data.

ORPHE TERMINALは、ORPHE COREの接続、Device Information、Date Time、ストリーミングデータをブラウザ上で確認するための開発用ツールです。

Open ORPHE TERMINAL ORPHE TERMINALを開く README

When to use it どんな時に使うか

Connection check 接続確認

Use CoreToolkit to connect one ORPHE CORE and confirm that notifications are arriving.

CoreToolkitでORPHE COREを1台接続し、通知データが届いているか確認します。

Device Information

Read or send Device Information bytes when checking settings and low-level behavior.

設定や低レイヤーの挙動を確認したい時に、Device Informationの読み書きを試します。

Date Time

Read or send Date Time bytes when checking recording and timestamp behavior.

記録やタイムスタンプまわりを確認したい時に、Date Timeの読み書きを試します。

CSV export CSV保存

Export received buffers as CSV for quick inspection or later analysis.

受信したバッファをCSVとして保存し、あとで確認・解析できます。

Basic workflow 基本的な使い方

  1. Open ORPHE TERMINAL in Chrome or another Web Bluetooth compatible browser. ChromeなどWeb Bluetoothに対応したブラウザでORPHE TERMINALを開きます。
  2. Turn on one ORPHE CORE and connect from the CoreToolkit switch at the top of the page. ORPHE COREを1台起動し、ページ上部のCoreToolkitスイッチから接続します。
  3. Use Read in Device Information or Date Time to inspect the current bytes. Device InformationまたはDate TimeのReadで現在のバイト列を確認します。
  4. Use the SENSOR_VALUES area to monitor incoming stream data and lost-data logs. SENSOR_VALUES欄でストリーミングデータやlost dataのログを確認します。
  5. Use clear, pause, and download csv while debugging. デバッグ中はclear、pause、download csvを使ってログを整理します。

Notes 注意点

  • This is a developer utility, not a beginner tutorial. これは初学者向けチュートリアルではなく、開発者向けの確認ツールです。
  • Send fields expect comma-separated hexadecimal bytes such as 01,02,03. Send欄には 01,02,03 のようなカンマ区切りの16進バイト列を入力します。
  • Avoid sending arbitrary bytes unless you know the target characteristic behavior. 対象Characteristicの挙動を理解していない場合、任意のバイト列を送信しないでください。
  • For first-time development, start with the LED guide or CoreToolkit.js guide first. 初めて開発する場合は、まずLED制御ガイドやCoreToolkit.jsガイドから始めるのがおすすめです。
