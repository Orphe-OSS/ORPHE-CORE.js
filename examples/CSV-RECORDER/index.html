CSV Recorder PoC · draft

Record ORPHE CORE callback payloads to a flat CSV (and to JSON for replay) using the draft CoreRecorder.js helper. One device, one session at a time.

Status: public-candidate (planned). Not yet listed in examples/catalog.json. Proposed catalog metadata is in README.md.

Web Bluetooth is disabled in this browser. Open this page in Chrome on macOS or Windows to connect ORPHE CORE.

How this page is wired (draft)
  1. CoreToolkit creates bles[0] for one ORPHE CORE.
  2. guardCoreToolkitBluetooth({ coreIds: [0] }) disables the BLE switch on browsers without Web Bluetooth.
  3. The page replaces bles[0].gotConvertedAcc, gotConvertedGyro, gotEuler, gotQuat, gotGait, gotStride, gotPronation, gotLandingImpact, gotFootAngle, and gotStepsNumber with handlers that call CoreRecorder's feed* methods. No other example shares this page, so the callback ownership is unambiguous.
  4. Start / Stop manage one CoreRecorder instance. Reset clears its buffer.
