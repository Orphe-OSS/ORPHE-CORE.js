How this page is wired (draft)
  1. CoreToolkit creates bles[0] for one ORPHE CORE.
  2. guardCoreToolkitBluetooth({ coreIds: [0] }) disables the BLE switch on browsers without Web Bluetooth.
  3. The page replaces bles[0].gotFootAngle, gotLandingImpact, and gotPronation with handlers that update the metric cards, bin counters, and a 12-row recent-landing log. The three callbacks are timestamped and joined into a single landing row when they land within a 100 ms window.
  4. No analytics or recorder helper is required. The page reads the SDK callbacks directly so it can ship independently of any in-flight helper PR.
