### 2. ⌨️ キー入力時のレーンインジケーター光反応

**実装内容**:
- 下部の矢印ブロックがキーボード押下時に発光
- 視覚的フィードバックで入力確認が容易に

**機能詳細**:
```javascript
// 押下時の効果:
- 背景が矢印の色で光る（shadowBlur: 30）
- 矢印が大きくなる（24px → 32px）
- 矢印が白色で明るく表示
- キーヒントも白色に変化
- 10フレーム（約0.17秒）間表示
```

**動作の流れ**:
1. キーボード押下 → `PlayerManager.handleInput(lane)`
2. `GameRenderer.triggerLanePress(lane)` が呼ばれる
3. `lanePressStates[lane] = true` に設定
4. `lanePressTimers[lane] = 10` フレーム
5. 毎フレームタイマー減少、0になったら消灯

### 3. 🎯 落下矢印のフォントを太く

**変更内容**:
- フォントサイズ: `32px` → `40px`
- フォントウェイト: `bold` → `bold Arial Black`
- 黒い縁取り追加（strokeStyle: '#000000', lineWidth: 2）

**効果**:
- 矢印の視認性が大幅に向上
- 高速で落ちてくる矢印も見やすい
- 背景とのコントラストが強化

### 4. ⏹️ QUIT GAME ボタン追加

**新機能**:
- プレイ中に途中終了可能
- 赤色の目立つボタン（`background-color: #FF4444`）
- 押すと即座にスコア表示画面へ

**ボタン表示ロジック**:
```
ゲーム待機中:
  [START GAME] 表示
  [QUIT GAME] 非表示
  [RESTART] 非表示

プレイ中:
  [START GAME] 非表示
  [QUIT GAME] 表示 ← NEW!
  [RESTART] 非表示

終了後:
  [START GAME] 非表示
  [QUIT GAME] 非表示
  [RESTART] 表示
```
