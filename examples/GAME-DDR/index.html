操作方法 / Controls

キーボード / Keyboard

  • ← 左 / Left
  • ↑ 上 / Up
  • ↓ 下 / Down
  • → 右 / Right

ORPHE CORE

  • 前へステップ: ↑
  • 後ろへステップ: ↓
  • 左へステップ: ←
  • 右へステップ: →
  • 左右は CORE の LEFT/RIGHT 設定で判定します
  • コツ: 足を大きく広げず、小さくステップすると判定されやすくなります

※ 流れてくる矢印が、判定位置の枠にぴったり重なるタイミングで入力してください。ノーツがないときの入力はミスにならず、枠が薄く光るだけです

* Step when the arrow exactly covers its outline in the step zone. Inputs with no note nearby are not a miss.
