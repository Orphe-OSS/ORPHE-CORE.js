🎮 操作方法 / Controls:

• 足踏み（加速度 > 閾値） → 前進加速

• つま先を上げる（PITCH < -閾値） → ジャンプ

• Stamp feet (Accel > threshold) → Accelerate forward

• Lift toe up (Pitch < -threshold) → Jump
