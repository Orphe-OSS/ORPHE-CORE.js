# Kick Challenge

右足を上げるとゲームスタート。ボールが前から飛んでくるので、足を円に合わせて、画面の指示どおり「弱く」「強く」蹴り返すキックゲームです。
キックの強さは ORPHE CORE の加速度で判定し、ゲージのラインより下なら「弱く」、上なら「強く」が成功。10 球でスコアが出ます。

## このexampleで学べること

- 加速度の大きさ（|acc|）をキックの強さとして使い、しきい値で「弱く / 強く」を判定する方法
- カメラの姿勢推定（MediaPipe Pose Landmarker）と ORPHE CORE のデータを組み合わせる方法
  （CORE の加速度が大きくなった区間の、画面上の足の位置で当たり判定）
- 正面から撮った姿勢を「後ろから見た」3D ビューに変換して、ゲーム画面に使う方法
- 画面・カメラ映像・CORE の生データ・姿勢・判定をまとめて記録する方法（REC）

## 使うデータ

- 加速度 (gotConvertedAcc, 実Gスケール) — キックの検出と強さ
- 姿勢推定のボーン（カメラ） — 足の位置
- 画面右の CORE パネルでは角速度・姿勢・歩行解析の値も確認できます

## 必要なもの

- ORPHE CORE 1〜2 台（ボールは接続した CORE の足に飛んできます）
- Webカメラ
- Chrome / Edge（Web Bluetooth）

## 起動方法

1. ローカルサーバを起動します。
2. ブラウザで `examples/GAME-KICK-CHALLENGE/` を開きます。
3. 「カメラ開始」を押してカメラを許可し、カメラに向かって全身が映る位置に立ちます。
4. ヘッダーの `CORE 01` / `CORE 02` スイッチから ORPHE CORE へ接続し、各 CORE パネルで装着した足（左足 / 右足）を選びます。
   ヘッダーの ⇄ ボタンで、2台の左右をまとめて入れ替えられます（ホバーで今の割り当てを表示）。
5. 右足を上げて約 0.6 秒キープするとゲームが始まります（「ゲーム開始」ボタンでも開始できます）。

GitHub Pagesでも試せます。

<https://orphe-oss.github.io/ORPHE-CORE.js/examples/GAME-KICK-CHALLENGE/>

## 遊び方

- 画面中央上部に「右足で / 弱く蹴って」のような指示が出ます。
- ボールは前方の奥から跳ねながら近づき、円の位置に来ます。指示された足を円に合わせて蹴り返してください。
- 判定は 3 つです。
  - 「ナイス！」: 足が円の中にあり、強さも指示どおり
  - 「強すぎ！」「弱すぎ！」: 強さが指示と違う（ボールは左右に曲がって飛びます）
  - 「位置ずれ！」: 蹴ったときに足が円に入っていない
- ボールが足元を抜けるまでに蹴らないと「ミス！」になります。
- 左のゲージは今の加速度と、成功ラインを表示します。ゲージ（初期 6.0G）とキック検出（初期 2.0G）はスライダーで調整できます。
  CORE の取り付け位置や人によって値が変わるので、何回か蹴ってゲージの ▶（直近のピーク）を見ながら合わせてください。

## 画面

- 16:9 の画面を縦長 8:9 の 2 枚に分け、左にゲーム画面（自分を後ろから見たボーン）、右に足元の実写を並べます。

## REC（記録）

ツールバーの `REC`（または `R` キー）で記録を開始・停止します。停止すると次の内容を 1 つの zip にまとめて保存します。
時刻はすべて REC 開始からの経過ミリ秒 `t_ms` でそろえています。

| ファイル | 内容 |
| --- | --- |
| `screen.webm` | 画面の録画（スライド用） |
| `camera.webm` | カメラの生映像 |
| `core01_sensor.csv` / `core02_sensor.csv` | CORE のセンサー値 1 サンプル 1 行（正規化生値・G / deg/s 換算値・クォータニオン・オイラー角・CORE のタイムスタンプ） |
| `events.jsonl` | CORE の歩行解析イベントと、ゲームのイベント（game_start / ball / kick / judge / game_over） |
| `pose.jsonl` | 姿勢推定の結果（MediaPipe 33 点の画像座標とワールド座標） |
| `meta.json` | 開始時刻・設定・CORE の情報・各動画の開始オフセット |
