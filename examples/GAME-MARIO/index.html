ORPHE CORE 2D ACTION!

ORPHE COREを使った2Dアクションゲームです。

This is a 2D action game using ORPHE CORE.

ORPHE COREを足に装着し、前傾+振動で前進、後傾+振動でジャンプ、大きく後傾で後退！敵を倒してゴールを目指そう！

Attach one ORPHE CORE to your foot. Lean forward + shake to move forward, lean back + shake to jump, keep leaning back to move backward! Defeat enemies and reach the goal!

🎮 操作方法 / Controls:

• Lean forward + Shake → Move forward

• Lean back + Shake → Jump

• Keep leaning back → Move backward
