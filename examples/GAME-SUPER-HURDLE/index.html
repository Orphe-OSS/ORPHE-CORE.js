🎮 操作方法 / Controls

• 足踏み（加速度 > 1.1G） → 前進加速

• つま先を上げる（PITCH < -0.15 rad） → ジャンプ

• ジャンプ・スタミナのルールは下の「ルール」で切り替えできます

• Stamp feet (Accel > 1.1G) → Accelerate forward

• Lift toe up (Pitch < -0.15 rad) → Jump

• Jump and stamina rules can be switched under "Rules" below

👟 ORPHE INSOLE

つま先を上げたとき、上のモニターの Pitch がマイナス（左）に振れてオレンジになれば正しい向きです。逆に振れる場合は「反転」にしてください。加速・ジャンプの閾値は CORE と共通です。
