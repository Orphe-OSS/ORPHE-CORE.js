使い方
  1. カメラ開始 → 上部の CoreToolkit のスイッチで ORPHE CORE に接続（加速度 ±16G / ジャイロ ±2000dps で接続します）
  2. 自動校正: 画面の指示に従うと、地面と基準の高さ（身長）の線が自動で合います。 手動で合わせる場合は、緑の線を地面、オレンジの線を高さの分かる位置（立った人の頭のてっぺん等）に合わせ、 設定で「基準の高さ」を入力。イラストは跳ぶ場所まで横にドラッグ。
  3. 1 秒ほど静止してからジャンプ。最高点の写真と、飛び越えたものが表示されます。
  4. 録画: 停止すると生データ・動画・ジャンプ一覧・校正情報を zip で保存します。
  5. 映像右上の で全画面（右側に記録画像、クリックで拡大）。
スマホのカメラを使う

iPhone（Mac の場合）: Mac の「連係カメラ」で iPhone がカメラ一覧に出ます。iPhone を Mac の近くに置き、カメラの一覧から iPhone を選んでください。センサーは Mac に接続します。
Android: Android の Chrome は Web Bluetooth に対応しているので、スマホだけで計測できます。GitHub Pages など https で公開されたこのページを、スマホの Chrome でそのまま開いてください（カメラと Web Bluetooth は https でのみ使えます）。
iPhone 単体: iOS のブラウザは Web Bluetooth に対応していないため、センサー接続には PC か Android が必要です。
