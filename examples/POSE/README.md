# POSE
POSE is an example to use MediaPipe Pose, p5js and ORPHE-CORE.js in a single project.

  * MediaPipe Pose: https://google.github.io/mediapipe/solutions/pose.html

## Runtime assets

This example loads MediaPipe Pose runtime/model assets from jsDelivr:

`https://cdn.jsdelivr.net/npm/@mediapipe/pose@0.5/`

The files are intentionally not vendored in this repository, so the example requires internet access when it starts.
