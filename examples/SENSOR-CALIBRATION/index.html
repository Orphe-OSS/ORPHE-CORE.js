ORPHE CORE Sensor Calibration Tool

使い方

  1. ORPHE COREを接続
  2. 記録したいジェスチャーボタンをクリック
  3. 3秒間のカウントダウン後、ジェスチャーを実行
  4. 自動的に記録が停止
  5. 複数回記録してJSONエクスポート

Device Configuration

設定を変更すると自動的にデバイスに反映されます。記録前に正しい設定を選択してください。
