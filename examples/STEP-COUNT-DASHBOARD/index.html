How this page is wired (draft)
  1. CoreToolkit creates bles[0] for one ORPHE CORE.
  2. guardCoreToolkitBluetooth({ coreIds: [0] }) disables the BLE switch on browsers without Web Bluetooth.
  3. The page replaces bles[0].gotConvertedAcc, gotGait, gotStride, gotPronation, and gotStepsNumber with handlers that call CoreAnalytics's opt-in feed* methods.
  4. A 250 ms timer reads analytics.getSessionSummary(), getRollingCadence(), getStrideStats(), getLastCMJ(), and compareToBaseline() to refresh the panels.
