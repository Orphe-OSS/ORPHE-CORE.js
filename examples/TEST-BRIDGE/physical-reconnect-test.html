実機チェック手順
  1. このページを2つのタブで開く。
  2. Tab Aで「接続 / 再接続 / 切り替え」を押し、BLE選択ダイアログからORPHE COREを選ぶ。
  3. Tab Bで「接続 / 再接続 / 切り替え」を押し、BLEダイアログなしでSecondaryになることを確認する。
  4. Tab Aで「切断」を押し、Tab Bが同じORPHE COREへ自動再接続してPrimaryになることを確認する。
  5. Primary接続中に同じボタンをもう一度押し、別のCOREを選ぶと記憶済みデバイスが更新されることを確認する。
