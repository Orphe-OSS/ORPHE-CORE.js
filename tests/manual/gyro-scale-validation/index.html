ORPHE CORE / v1.4.0 PHYSICAL DEVICE TEST

ジャイロ物理単位換算 実機チェック

PURPOSE

gyro 感度修正（理想 Q15 → データシート感度）の実機確認

v1.4.0 で gotConvertedGyro の deg/s 換算を「理想 Q15（raw/32768×range）」から 「データシート感度（±2000 dps で 0.07 dps/LSB）」に修正しました。新しい値は従来比で 16bit パケット（ヘッダ 50）では約 +14.7%、8bit 圧縮パケット（ヘッダ 40、CORE 2.0）では約 +13.8% になります。 このページは、実機を机上で水平に回転させたときの gyro-z の積分角 と、FW が計算する quaternion 由来の yaw 変化量 を比較し、比率が 1.0 付近なら新換算が正しいことを確認します （旧換算のままだと比率は約 0.87 になります）。

  1. 接続 — 下のスイッチを ON にして CORE を選ぶ（CORE 1.x / 3.0 は 16bit、CORE 2.0 は 8bit パケット。どちらか自動判定して表示）
  2. 静置テスト — 机に置いたまま 10 秒。3 軸の平均が ±3 dps 以内なら PASS
  3. 回転テスト — 目標角度を選んで開始 → CORE を机の上で水平に保ったまま目標角度だけ回す（机の辺に合わせると正確）→ 停止
  4. 判定 — 比率 0.93〜1.07 で PASS。約 0.87 なら旧換算のまま。手元に両世代あれば 2.0 でも同じ手順を繰り返す
  5. 証跡 — 「ログをコピー」を PR #124 のコメントに貼る
